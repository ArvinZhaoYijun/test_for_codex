# 移动端聊天机器人 Web 页面

一个简洁美观的移动端聊天机器人界面，使用纯前端技术实现。

## 功能特点

- 📱 移动端优化设计
- 💬 流畅的聊天界面
- 🤖 模拟 AI 回复（关键词匹配 + 随机回复）
- ✨ 打字动画效果
- 🎨 渐变色主题设计

## 文件结构

```
.
├── index.html   # 主页面
├── style.css    # 样式文件
└── script.js    # JavaScript 逻辑
```

## 如何使用

### 方法一：直接打开 HTML 文件

1. 双击 `index.html` 文件
2. 会在浏览器中打开页面
3. 开始聊天！

### 方法二：使用本地服务器（推荐）

```bash
# 如果安装了 Python
python -m http.server 8000

# 如果安装了 Node.js
npx http-server
```

然后在浏览器访问 `http://localhost:8000`

### 在手机上测试

1. 启动本地服务器
2. 查看电脑 IP 地址（如 `192.168.1.100`）
3. 在手机浏览器访问 `http://192.168.1.100:8000`

## 聊天机器人功能

当前是**模拟对话**，支持以下关键词：

- "你好" - 打招呼
- "帮助" - 获取帮助信息
- "谢谢" - 礼貌用语
- "时间" - 显示当前时间
- "名字" - 介绍自己
- "笑话" - 讲个笑话

其他输入会得到随机的通用回复。

## 技术栈

- HTML5
- CSS3（Flexbox、动画、渐变）
- 原生 JavaScript（无依赖）
